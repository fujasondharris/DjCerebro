dj-supermercado real SFX pack — provenance and licensing record
Compiled: 2026-07-26
Corrected: 2026-07-26 (review panel, see the vinyl_brake.mp3 entry below)
All files verified via ffprobe (real audio stream, not truncated), converted to
44.1kHz stereo MP3, loudness-normalized with ffmpeg's loudnorm filter (two-pass,
target -14 LUFS integrated, -1.5 dBTP true-peak ceiling). Where a source clip's
true peak was too close to 0 dBFS to reach -14 LUFS without exceeding the true-peak
ceiling (laser_zap.mp3), the true-peak ceiling was honored instead and the achieved
LUFS is noted below — this is the correct trade-off for punchy, transient one-shots
(avoids clipping/distortion over hitting the number exactly). vinyl_brake.mp3 is
the EXCEPTION to that — see its own entry below: the -1.5 dBTP ceiling was NOT
actually met there, and the original writeup here was wrong to imply it was.

The "Direct file" URLs below are Freesound/Mixkit CDN preview paths of each
licensed asset, not a canonical/original master file — that's simply how both
services serve their licensed audio (preview encodes are the deliverable, not
a lossy stand-in for something better hosted elsewhere); noted here so a future
reader doesn't mistake "preview" in the path for "not the real thing."

Sources considered but rejected (for the record):
- Pixabay (pixabay.com/sound-effects/) — search pages return HTTP 403 to both
  the WebFetch tool and curl (Cloudflare bot protection); a Wayback Machine
  snapshot of the airhorn search page also failed to yield usable audio URLs.
  No Pixabay files were usable within this task's scope.
- freesound.org/people/omanyte99/sounds/784969/ ("Airhorn.WAV", CC0) — rejected
  because the uploader's own description states it was generated from the
  "Whelen-Airhorn" GitHub source code, i.e. synthesized, not a real recording.
- freesound.org/people/guitarguy1985/sounds/64476/ (CC0 "air horn") — rejected,
  uploader states "No recordings were used" (synthesized civil-defence horn).
- freesound.org/people/tim.kahn/sounds/265977/ and
  freesound.org/people/neilyhype/sounds/557337/ — real airhorn recordings but
  licensed Attribution-NonCommercial, not CC0; skipped per source policy
  (Freesound entries must be CC0-only for this pack).
- Mixkit "rewind" and "spin" categories — real assets but tape/mechanical
  rewind sounds, not vinyl-specific; freesound's TasmanianPower clip above was
  a better vinyl-specific match so those were not used.
